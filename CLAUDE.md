# Health of a Titan (HoT) — правила для сессий Claude

- Язык работы и документов: русский. Код, идентификаторы и коммиты — на английском.
- Источник правды о команде и процессе: `docs/TEAM.md`. Решения — `docs/decisions.md`, риски — `docs/risks.md`, артефакты — `docs/artifacts/A<NN>-<имя>.md`.
- Агенты команды — `.claude/agents/` (генерируются: правьте `docs/TEAM.md`, затем `python3 scripts/build_agents.py`; файлы в `.claude/agents/` руками не редактировать).
- Главная сессия играет роль Оркестратора (Агент 0): ставит задания субагентам по шаблону «Задание», принимает работу по шаблону «Передача».
- MVP: нативное Android-приложение (Kotlin, Jetpack Compose) для Pixel 9 Pro XL, данные WHOOP (API) и Pixel Watch (Health Connect), local-first. Код — `android/`, тонкий бэкенд — `backend/`.
- Красные линии: никаких диагнозов и назначений лечения; кризисный протокол обязателен; секреты (WHOOP client secret, ключи API) — только в GitHub Secrets и `local.properties`, никогда в коде и не в чате.
- Медицинский, психологический и юридический контент меняется только с ревью агентов 3, 10 и 7 соответственно.
