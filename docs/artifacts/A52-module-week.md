# A52 · Модуль «Неделя»: структура, показатели, сценарии

> **ID:** A52 · **Версия:** v0.1 · **Статус:** структура принята основателем («по Неделе да… проработайте максимально самостоятельно»), детали — решение команды (D-044) · **Дата:** 2026-11-07
> **Ведёт:** Агент 4 · **Участники:** 18 (метрики, модель), 1, 8 (цели, работа), 3 (вето), 10 (вето), 12 (нагрузка), 9 (закономерности)
> **Опора:** A45 §13 (контрольный контур — переработан здесь), A42 §3 (цикл), A46 v0.3 (Сегодня), A49 (ритуалы), A51 (модель дня), D-042, D-043.

## Резюме
- **Вопрос модуля:** «Держится ли моя неделя и что поправить на следующей?» Горизонт — пн–вс.
- **Семь блоков:** шапка → Неделя одним взглядом → Цели недели → Опоры за неделю → Тело за неделю → Закономерности → Итог и сборка (воскресенье).
- **Главный показатель — «Дни в опоре», N из 7, метка на 4.** Он заменяет «Дни в движении»: день держится, если сделано хотя бы одно дело (мини считается) и наполнено ≥ 3 опор из 5.
- **Цели недели — мост между Путём и Сегодня.** Их предлагает HoT из цели цикла и запаса прошлой недели; человек одобряет в воскресенье; дни берут дела отсюда.
- **Пн–сб — живой контур без пушей, воскресенье — ритуал «Итог и сборка» (3–5 мин).**

## 2. Блоки
### 2.1 Неделя одним взглядом
| | |
|---|---|
| **Семь колонн** | пн–вс; цвет — режим дня; наполнение — доля наполненных опор; метка-точка — сделано ≥ 1 дела; «сегодня» обведено; будущие дни — контур |
| **Дни в опоре** | N из 7, шкала с меткой 4 |
| **Цели недели** | сделано / запланировано, одним числом |
| **Тап по колонне** | день целиком только для чтения: режим, опоры, дела, ритуалы, хокку |

**Почему «Дни в опоре», а не индекс** (Агент 18): день считается, если **≥ 1 дела дня сделано (мини считается) И ≥ 3 из 5 опор ≥ 70 % своей нормы** (в Бережно — ≥ 50 %). Отвергнуты: индекс 0–100 (вето A25 на «балл здоровья», прячет перекосы); «Дни в движении» A45 §13 (видит только тело, а опоры и работа теперь равноправны); серия дней подряд (вето 10). **Неделя в опоре** = ≥ 4 дней в опоре и ≥ 1 шаг пути — North Star (замена A10 §5, согласовать с Агентом 1).
**Устойчивость:** плохой день — 1 из 7, ничего не вычитается; `SICK` — день засчитывается отдыхом; неделя возвращения после 7+ дней — метка 2 из 7.

### 2.2 Цели недели
| | |
|---|---|
| **Что это** | 3–5 процессных целей на неделю по сферам: тело, работа, сон, еда, разум; одна из них — шаг пути (цель цикла A42) |
| **Откуда** | HoT считает из этапа цели цикла (A42 §3.3) и запаса прошлой недели; цели работы — Агент 8 (фокус-блоки, шаг навыка) |
| **Адаптация** | прошлая неделя выполнена < 50 % или ≥ 3 дней Бережно → цель на 1 шаг легче; ≥ 90 % и Заряд в норме → предложить +1 шаг (человек решает) |
| **Как дни берут дела** | утром HoT выбирает 1–3 дела из незакрытых целей по запасу дня и равномерности (A51 §3.1); «Не сегодня» возвращает дело сюда |
| **Вид** | строка: цель · точки выполнения · «N из M» |
| **Тап** | цель → её история и «поменять» (без штрафа) |

### 2.3 Опоры за неделю
| Опора | Что показываем | Источник | Перекос (наклон, не оценка) |
|---|---|---|---|
| Усердие ↔ восстановление | Весы: нагрузка против восстановления по дням | WHOOP strain, recovery | «копится» > +1 в ≥ 3 днях; «недогрузка» < −1 всю неделю при Заряде в норме |
| Движение | дни с нормой шагов; часы с движением в среднем; минуты в зонах к 150–300 (ВОЗ) | WHOOP `step_count`, workouts `zone_durations`; Health Connect | < 3 дней с нормой |
| Питание | дни по плану; белок к норме; **охват микроэлементов за неделю** (топ-3 ниже нормы) | отметки, фото (A46 §2.3) | белок < 70 % в ≥ 4 днях; микроэлемент < 50 % за неделю |
| Вода | средний % нормы | тапы, Health Connect `Hydration` | < 60 % |
| Сон | долг за 7 дней, регулярность, ночи ≥ потребности | WHOOP sleep | долг ≥ 5 ч; регулярность < 60 % |
| Вес (только если открыта цель по весу, D-043) | средний за неделю и тренд, без ежедневных скачков | ввод, весы через Health Connect | — (без оценок; скрыт при `ed_care`) |

Перекос — пиктограмма Весов и одна фраза «факт + что можно сделать», без красного. В Бережно, неделе возвращения и 7 дней после `StormNet` негативные перекосы скрыты.

### 2.4 Тело за неделю
Пульс покоя, вариабельность пульса, частота дыхания, кислород, температура кожи — стрелкой к личному коридору 30 дней и мини-графиком 7 дней. Тап → график 90 дней. **Красные флаги — не перекосы:** пульс покоя ≥ +2 SD 3 ночи подряд, `StormNet` → `SafetyEvent` и «Помощь» (SAF-05 живёт здесь). Тексты — Агент 3.

### 2.5 Закономерности
- **До 3 в неделю**, только при ≥ 6 точках данных и устойчивом эффекте; формулировка «связь, не причина» (метод — Агент 9).
- Источники: опоры с временем (кофе, ужин, экраны), ответы ритуалов, Передышки («что сбивает»), «Работа сегодня», ты ↔ WHOOP.
- Каждая заканчивается действием «Попробовать на неделе» → становится маленькой целью недели (необязательно).
- Без морали, без «плохих» привычек; слой «Только ты» (S5) сюда не попадает.

### 2.6 Итог и сборка (воскресенье, 3–5 мин, ритуал A49)
1. **Неделя одним кадром:** Титан, дни в опоре, одна пара «было → стало».
2. **Что сработало:** одна закономерность или победа.
3. **Работа (Агент 8):** «Чем гордишься на этой неделе?» → в «За плечами · Взято»; «Что тянется?» → в «Несу» или в цель недели.
4. **Один перекос → одно предложение:** «Беру · Как есть · Полегче».
5. **Цели следующей недели:** HoT предлагает, человек одобряет или правит каждую одним тапом.
6. **Вперёд:** хокку недели, Титан.
Пропущено в воскресенье — доступно до вторника; потом HoT собирает неделю сам и показывает «Собрал сам — поправь, если нужно». Никаких «ты пропустил итог».

## 4. Модель данных и код (Агенты 18, 5, 13)
- `WeekPlan { weekStart (пн), goals: [WeekGoal { sphere, kind, target, unit, progress, source: path|work|pattern }] }`; `DayTask.weekGoalId`.
- `DayScore { dayInSupport: Bool, supportsFilled: 0..5, tasksDone }` считается в 04:00 следующего дня.
- Неделя — по календарю пн–вс (сейчас `weekOf` считает от старта цели — исправить).
- WHOOP: `cycle.step_count`, `strain`, workouts `zone_durations`, sleep и recovery за 30 дней для коридоров.
- `Pattern { text, evidenceN, effect, actionGoal? }` — движок правил Агента 9, без ИИ-выводов в цифрах.

## 5. Правила, проверяемые тестом
| ID | Правило |
|---|---|
| W-01 | «Дни в опоре» считаются строго по §2.1; мини-версия засчитывается |

| W-07 | вес виден только при открытой цели по весу и никогда при `ed_care` |

## 6. Вето и условия
- **Агент 3:** нет «балла здоровья» и биовозраста здесь; калории и вес — только по D-043, диапазонами и трендом; формулировки «Тела за неделю» без диагнозов.
- **Агент 10:** нет сравнения с другими, серий и счётчиков пропусков; настроение не оценивается; «Только ты» не попадает в закономерности и итог.
- **Агент 8:** цели работы — процессные; «гордость недели» обязательна в итоге, «что тянется» — без стыда.
