# Скелет Титана: модель, разрывы, петли (роли агентов 1, 18 и 14)

Прочитаны D-036…D-050, A45, A47–A57, а также A37, A42, A44, A10, A25 и A26 (по ключевым разделам). Файлы не менялись, коммитов нет.

## 0. Главное
1. **Модули по отдельности сильные, но единой модели снова нет.** Единственная «модель-источник» — A45 §3: 14 объектов. Она устарела: в ней шесть сфер, `Tier`, одна цель на цикл. В ней нет опор, дел, цели недели (`WeekGoal`), эксперимента, Скульптуры, `BehindItem`, Титана горизонта. Каждый новый артефакт достраивал свою модель. A47, A54 и A56 описывают «За плечами» тремя разными способами.
2. **Три критичных разрыва:**
   - (а) **Холодный старт.** Без цели нет целей недели, без них нет дел. Без дел «День в опоре» невозможен, North Star — ноль.
   - (б) **Воскресенье 7-го дня перегружено:** около 15 механик за «≤ 5 минут».
   - (в) **Титан горизонта идёт по календарю, пока человек молчит.** При этом A56 запрещает HoT ставить паузу самому.
3. **Как собрать целое:** один Титан и четыре масштаба времени. У каждого материала одно время: **свет = день, камень = неделя, огонь = рубеж, кольцо = этап, звезда = «Зачем», основание = Дано**. Плюс одна шина событий и одна летопись «Взято».

## 1. Единая модель Титана

              └──▲──────▲───────────┬──────▲───────────┬─────────┘
   огни, кольца, │      │ остаток    │канди- │отпущено   │фильтр R3, A09, A40/41,
   «узнали»      │      │ этапа      │даты Э1│           │скрытие фитнес-возраста

                 │ WeekGoal(source=stage) · рычаг→Эксперимент      ▲ искры недели, шаг Т.горизонта
                 ▼                                                 │ (вс)
              НЕДЕЛЯ: WeekPlan (3–5 целей + Эксперимент) ──▶ Итог и сборка (вс) ──▶ Скульптура

## 3. Петли: где замкнуты, где разомкнуты
| Петля | Механизм | Статус | Что сделать |
|---|---|---|---|
| День → неделя | `DayScore` (04:00) → «Дни в опоре»; «Не сегодня» → цель недели | **разомкнута на старте:** без цели недели нет дел | «Стартовая неделя» (§6, П-1) |
| Граница суток | 04:00 (A52), цикл WHOOP, «до 04:00» после Приземления | не определена для смен и ночных подъёмов | сутки = цикл WHOOP; запасной вариант — 04:00 |
| Опоры → день | «≥ 3 из 5 ≥ 70 %» | разомкнута при `ed_care` (Питание скрыто) и без WHOOP (нет Усердия); перебор Усердия считать наполнением? | «≥ 60 % доступных опор»; Усердие — «в коридоре» |
| Неделя → этап | цели этапа → недели → искры → Срез | **нет правила «3 из 4» для цели из нескольких составляющих** | этап взят: каждая ведущая — ≥ 3 из 4 последних недель или рубеж; бережущая — «держим» |
| Неделя этапа ↔ календарь | старт в чт–вс — «только первый шаг» | шаг Титана горизонта в первое вс не определён | неделя 0 = неполная; шаги — с первого пн |
| Этап → Взято | Встреча → кольцо, «3 из 4», остаток → «Несу» | замкнута после правки №11 | — |
| Несу → новая цель | Э1 «Из того, что несёшь» | замкнута; нет генератора «следующей главы» после TAKEN (в A42 — устаревшая ротация сфер) | после Встречи: 1 предложение из «Несу» + стихия с наименьшим светом |
| Дано → фильтры | R3, A09, A40/41, фитнес-возраст, эксперимент | замкнута; флаги бережности (`ed_care`) хранятся неизвестно где | «Дано · скрытые флаги» (не показываются) |
| Закономерность → эксперимент → знание | вс → неделя → «узнали» | **знание уходит в никуда** (№25) | «Взято › Знаю о себе» → подсказки Э4 |
| Винс → изменения | ChangeProposal | метки «Что я записал» ≠ «Дано · со слов» | метка → тап «Сохранить в Дано» (source=PERSON) |
| Перекос → Несу | «3 из 4» итогов (A47) и «Что тянется» (A52) — два входа | дубль | «Что тянется» → цель недели; «Несу» — только по правилу A47 |

## 6. «Скелет Титана»

**Сущности** (12 вместо 14 устаревших):
1. `Person`
2. `Day`: режим, опоры, `DayScore`
3. `CheckIn` (фазы)
4. `DayTask`: source ∈ {WEEK_GOAL, GIVEN_VISIT, CARRY_OVER, PERSON}, ≤ 3
5. `WeekPlan` / `WeekGoal`: source ∈ {STAGE, START, EXPERIMENT, PERSON}
6. `WeekRecord`: дни в опоре, параметры Скульптуры, гордость
7. `PracticalGoal` + `GoalComponent` + `GoalVersion`
8. `Stage`: 12 календарных недель, вехи 4/8/12
9. Каталог `Component` (14) и `MarkLadder`
10. `BehindItem` (layer × kind × source). Взято: GOAL_TAKEN, STAGE, MARK, FIRST, TIER, RECORD, BEFORE_US, STRENGTH, LEARNED
11. `SafetyState`
12. `ChangeProposal`

Титан, Срез, Скульптура и Титан горизонта не хранятся: это проекции.

**Правила:**
- **П-1.** Нет цели → «стартовая неделя»: 2–3 цели недели из данных и знакомства.
- **П-2.** Каждое дело ссылается на цель недели или на источник из списка выше.
- **П-3.** Сутки = цикл WHOOP, запасной вариант — 04:00; неделя — пн–вс; этап выровнен по понедельникам.
- **П-4.** Материал = масштаб времени: свет — день, камень — неделя, искра — недельный сдвиг, огонь — рубеж, кольцо — этап, звезда — «Зачем», основание — Дано. Огни взятых рубежей видны во всех четырёх модулях (это и есть «один Титан»).
- **П-5.** Рычаг — узкое место; эксперимент — по рычагу, без цели — по главной закономерности.
- **П-6.** Кольцо — за каждый завершённый этап; «взята» — отдельная запись.
- **П-7.** Цель видна ровно в одном слое (P-22); «Несу» — только из перечня источников.
- **П-8.** Любое изменение Пути — через ChangeProposal; Винс — тоже.
- **П-9.** `SafetyState` и «тишина ≥ 7 дней» останавливают календарь этапа.
- **П-10.** Бюджеты: ≤ 2 пушей в день, ≤ 1 нового понятия в неделю, воскресенье ≤ 5 экранов, ≤ 1 момента на «Сегодня» в день.
