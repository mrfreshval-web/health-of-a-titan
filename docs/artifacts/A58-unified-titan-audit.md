## Резюме
1. **Каждый модуль силён, но единого Титана пока нет.** Его нет ни в модели, ни в коде, ни в картинке. Каждый артефакт достраивал свою модель:
   - модель A45 устарела (шесть сфер), а A47, A54 и A56 описывают «За плечами» тремя способами;
   - найдено 34 противоречия между артефактами;
   - в коде Титан нарисован пятью несвязанными способами;
   - вся логика дня лежит внутри модуля WHOOP;
   - модели Недели в коде нет.
2. **Пять системных разрывов на стыках модулей:**
   - нет единого «состояния жизни» (у Пути есть пауза, у дня — болезнь, у Винса — бережный режим);
   - нет арбитра пушей и церемоний;
   - холодный старт: без цели нет дел, без дел нет «Дня в опоре»;
   - флаги безопасности теряются по пути (беременность, лекарства, `ed_care`, флаги в контексте Винса);
   - знание о себе (эксперименты, открытия, письма) уходит в никуда.
3. **Перегрузка:**
   - около 60 понятий за первые 30 дней;
   - примерно 15 механик в первое воскресенье;
   - до 7 касаний в день;
   - 12 «героических» моментов при лимите 6.
4. **Рынок.** ИИ-коуч на данных браслета есть уже у всех: WHOOP, Oura, Google, Samsung, Garmin, Bevel. Рынок уходит в медицину, а мы туда не идём.
   - Наше место — **сторона жизни**: шефство над рутиной, цель жизни, разобранная на три стихии, Титан горизонта, накопленная история и русский голос.
   - **Главный риск — WHOOP.** Он одновременно поставщик данных и прямой конкурент. Его условия API запрещают конкуренцию и позволяют отозвать доступ.
5. **Наука.** Местами мы обещаем больше, чем доказано:
   - микроэлементы по фото и БАДы;
   - точность фитнес-возраста;
   - вывод по эксперименту из 5 ночей;
   - формула «отклонений».

   Чего нет вовсе: профилактики и скринингов, давления, среды, женского здоровья, никотина.
6. **Психика.** Главный риск — «вечный проект себя»: самонаблюдение без выхода.
   - Нужны определение «HoT сработал» («Держу сам»), режим поддержки и право жить без цели.
7. **Объём.** Пакет фич — 70–85 агенто-дней при лимите 21–28. Строим **по календарю пользователя**: каждую функцию к тому дню, когда она впервые понадобится человеку.

## 1. Один Титан: скелет системы
**Принцип:** один Титан — четыре масштаба времени. **У каждого материала одно время.**

| Материал | Время | Где виден |
|---|---|---|
| свет | день | Титан дня, свет режима |
| камень | неделя | Скульптура, плиты Земли |
| искра | недельный сдвиг | воскресенье: из Скульптуры в Срез |
| огонь | рубеж | Титан горизонта → ты; виден во всех модулях |
| кольцо | этап (12 недель) | Встреча → «За плечами» |
| звезда | «Зачем» | зенит на всех вкладках |
| основание | Дано | под всеми кадрами |

**Мир «Край мира»** (Агенты 4, 17) — одна карта, модули — кадры одной камеры:
- **Вверху** свод, по которому идёт солнце дня; в зените звезда «Зачем».
- **В центре** Титан на горизонте, по бокам колонны (то, что держит HoT).
- **Внизу** Земля, Вода и основание «Дано».
- **На восток** (будущее) уходят тропа и Титан горизонта, **на запад** (прошлое) — кольца глав.
- **За спиной** — «За плечами».

| Вкладка | Кадр | Титан |
|---|---|---|
| Сегодня | крупный план | свет режима, колонны-опоры, солнце на дуге |
| Неделя | средний план, мастерская у ног | Скульптура из камня Земли, та же поза |
| Путь | общий план | весь Срез, горизонт, тропа |
| За плечами | обратный план (со спины) | кольца глав, ноша «Несу», основание «Дано» |

**Сущности** (Агенты 1, 18) — 12 вместо 14 устаревших:
1. `Person`
2. `Day` (режим, опоры, DayScore)
3. `CheckIn`
4. `DayTask`
5. `WeekPlan` / `WeekGoal`
6. `WeekRecord`
7. `PracticalGoal` + `GoalComponent` + `GoalVersion`
8. `Stage`
9. каталог `Component` и `MarkLadder`
10. `BehindItem`
11. `SafetyState`
12. `ChangeProposal`

Титан, Срез, Скульптура и Титан горизонта не хранятся: это **проекции** одной функции `TitanState`.

**Правила скелета:**
| ID | Правило |
|---|---|
| П-1 | Нет цели → «стартовая неделя»: 2–3 цели недели из данных и Знакомства. День не бывает пустым |
| П-2 | Каждое дело ссылается на цель недели или на источник (визит, перенос, своё) |
| П-3 | Сутки — цикл сна (запасной вариант — 04:00); неделя — пн–вс; этап выровнен по понедельникам («неделя 0» до первого понедельника) |
| П-4 | Материал = масштаб времени (таблица выше). Огни взятых рубежей видны во всех четырёх модулях |
| П-5 | Рычаг — это узкое место. Эксперимент недели — по рычагу, а без цели — по главной закономерности |
| П-6 | Кольцо — за каждый завершённый этап; «цель взята» — отдельная запись |
| П-7 | Цель живёт ровно в одном слое (Путь, Несу или Взято). «Знание о себе» (эксперименты, открытия) уходит во «Взято › Знаю о себе» |
| П-8 | Любое изменение Пути — только через «было → станет», в том числе через Винса |
| П-9 | **Единое «состояние жизни»** (§2) и тишина ≥ 7 дней останавливают календарь этапа во всех модулях |
| П-10 | **Бюджеты:** ≤ 2 проактивных пушей в день; ≤ 1 церемонии в день; ≤ 1 нового понятия в неделю; воскресенье — ≤ 5 экранов и ≤ 5 минут; ≤ 1 «момента» на Сегодня в день |

**Поток между модулями** (Агенты 5, 13):
- Факты пишутся в Room вместе с доменным событием в журнал (outbox).
- Чистые проекторы считают DayScore → неделю → прогресс Пути → «За плечами» → `TitanState`.
- Догоняющий пересчёт запускается при открытии, после синхронизации и при смене часового пояса, поэтому Doze и пропущенные будильники не страшны.
- Шаг Титана горизонта — функция календаря, а не событие.

## 2. Единое «состояние жизни» и шина безопасности
**Состояние жизни** — одно на всех. Его читают Сегодня, Неделя, Путь, ритуалы, Винс и пуши.

| Состояние | Что меняется везде |
|---|---|
| Обычно | — |
| Бережно (день или неделя) | ≤ 2 дел; перекосы скрыты; Титан держит свод одной рукой |
| Болезнь · Дети болеют | нагрузка снята; «Дни в опоре» не считаются; Эксперимент на паузе; Титан горизонта ждёт |
| Отпуск | без авто-Рассвета и воскресного пуша; неделя «отдых», а не «1 из 7» |
| Горе | без авто-Рассвета, хокку о силе, Скульптуры и вех; «год назад» пропускает этот период; мост к специалисту (вето 10) |
| Пауза HoT | ничего не зовёт; данные копятся тихо; при выходе — экспорт «Мой устав» |
| Новая глава жизни (ребёнок, работа, переезд, беременность) | перезнакомство по одной теме; пересчёт нормы за 14 дней; Перекрёсток для цели; при беременности весовые ветки сразу закрываются |

**Шина безопасности `SafetyState`** (Агенты 3, 10, 12):
- Один словарь флагов: стопы, клинические флаги (SICK, PREGNANT → POSTPARTUM, ED_CARE, MEDS_HR, INJURY…), бережные (STORM — одно имя вместо пяти) и флаги данных.
- Матрица политик «флаг × потребитель». Побеждает самое строгое; человек может ужесточить, но не ослабить; неизвестный флаг означает запрет.
- CI падает, если у потребителя нет политики для какого-то флага.
- **Винс получает коды запретов** (`forbid: breath_hold, calories, intensity>RPE6`), без названий состояний.
- **Знакомство спрашивает этап жизни:** беременность, кормление, менопауза, «не скажу».
- **При `ed_care` скрываются:** калории «Усердия», нутриенты, чипы еды, режим «Питание». Для флага есть правила выхода.

## 4. Наука: что исправить (вето 3, 10, 12)
| Сейчас | Решение |
|---|---|
| Охват микроэлементов по фото и БАДы «под цель» | **убрать** охват микроэлементов; БАДы — только справочник по запросу, без рекомендаций из данных |
| Фитнес-возраст ±2 года, темп за 4 недели, перцентиль в рубеже | ±5 лет; только направление выше порога ошибки; вехи раз в 12 недель; рубеж от личного старта, без перцентилей |
| Эксперимент: «+18 мин, 5 ночей из 6» | итог «узнали» без чисел, пока n < 8 и 8; дни «с» и «без» чередуются случайно (N-of-1) |
| Закономерности: «≥ 6 точек» | единый закон A25 §5 (8 и 8, бутстреп, фиксированный список пар) |
| «Отклонения: ≥ 3 из ±1 SD» | ±2 SD, ≥ 2 показателя, ≥ 2 ночи; формулировка «вне твоего обычного», без связи с болезнями |
| Питьё как опора дня | подсказка по жажде и жаре, не опора. **Опор 4 + Питьё-подсказка** — нужно решение |
| «Сон сегодня» — баллы гигиены сна | окно отбоя и свет, без баллов; глобальный режим «без цифр сна» |
| Стойка на одной ноге для всех | только 50+ |
| «Через тридцать лет» в маркетинге | «силы на жизнь»; долголетие не обещаем (ревью 7) |

**Добавить** (Дано и Неделя, HoT напоминает, а не назначает):
- календарь профилактики и прививок по возрасту и полу;
- домашнее давление раз в месяц;
- никотин и AUDIT-C — приватно, по желанию;
- цикл как поправка к норме (без тренировок по фазам);
- менопауза, пороги 18–24 и 65+;
- зубы, SPF, слух — разовые настройки.

**Среда** (Агент 11, модуль A16). Новый тип элемента — **«Настройка среды»**: делается один раз и проверяется раз в квартал.
- свет днём и вечером, спальня (темнота, 16–20 °C, тишина);
- **телефон за дверью спальни**;
- кухня на виду, рабочее место.

«Дано» делится на «не меняю» и «могу поменять». Приземление переносится к зарядке за дверью: сейчас ритуалы закрепляют телефон в кровати.

## 6. Юридическое и данные (Агенты 7, 5)
- **WHOOP.** Условия API запрещают конкуренцию и постоянные копии; доступ отзывается без уведомления. Нужно:
  - ревью Агента 7 и письмо в apisupport;
  - D-039 (загрузка всей истории WHOOP) — на паузе до ответа;
  - Health Connect как равный источник — до внешних пользователей.
- **До первого тестера обязательно:**
  - гранулярные согласия: данные о здоровье, LLM, фото, голос, статистика приложений, «Только ты», цели по весу, письмо;
  - возраст 18+;
  - **кризисные линии по странам**: сейчас в коде только США, а это красная линия;
  - экспорт и удаление;
  - зашифрованный бэкап.
- **Медицинская граница (MDR, FDA).**
  - «Отклонения», красный флаг пульса, SpO₂ и температура «вне коридора» близки к «признакам болезни» → формулировка «вне твоего обычного».
  - БАДы — только справочник.
- **Работодатель.** Ссылка на D-009 ошибочна, нужна отдельная запись: агрегаты при k ≥ 10, opt-in, без индивидуальных данных; эмоциональный слой в корпоративном контуре выключен (EU AI Act ст. 5(1)(f)).

## 7. Год человека: где модули работают вместе
**Сильнейшие точки:**
- Передышка («сбежал к себе, а не в ленту»);
- срыв без стыда (Бережно → скрытые перекосы → Перекрёсток);
- Встреча через 12 недель.

## 8. Порядок разработки: «по календарю пользователя» (Агенты 5, 13, 14)
- **Критический путь:** DayKey → журнал и проекторы → DayScore → цели недели → домен Пути → дела дня из целей → воскресный итог → `TitanState` → визуал Пути. LLM, фото еды и Lottie в критический путь не входят.
- **MVP:**
  - 1 цель, 3 шаблона;
  - статичный Срез;
  - Печать вместо Скульптуры;
  - Титан горизонта — позиция по формуле плюс пауза;
  - текстовый Винс;
  - без фото еды;
  - веха 4 нужна только через 4 недели после старта, Встреча — через 12.
- **Оценка:** визуал Пути ≈ 12 дней вместо 26,5; всё вместе — в пределах лимита, если функции готовы к своему дню в жизни пользователя, а не к G2.
