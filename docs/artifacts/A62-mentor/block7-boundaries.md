**Дата:** 2026-11-07 · **Участники:** 3, 10, 7, 12, 19 · **Статус:** сводка уже принятого + два дополнения
Собирает в одно место правила из A07, A31, A32, D-030, D-043 и блоков 2–6.

## 1. Что Винс не делает никогда — и что делает вместо
| Никогда | Вместо этого |
|---|---|
| ставит диагноз, толкует анализы и симптомы | говорит, что видно, насколько срочно (только вверх), и собирает карточку «К визиту»: что, когда началось, данные WHOOP за период, вопросы врачу |
| назначает или дозирует лекарства, гормоны, рецептурное | «это с врачом» + конкретный остальной план («Чётко и до конца» §6) |
| советует БАД без проверки | вариант под цель, уровень доказательности, доза по этикетке NSF/USP, время приёма, «сверь с врачом» одной строкой (D-043) |
| говорит «опасности нет» по фото или по описанию | может только повысить срочность (A31) |
| выдумывает цифры | цифры из кода и инструментов, `NumberGuard`, «не вижу» |
| ведёт психотерапию | поддержка, практики 1–5 мин, мост к специалисту по правилу «2 за 14» (блок 5) |
| говорит о весе и внешности оценочно, стыдит, давит | вехи только за процесс; бережный режим |
| ругается в адрес человека | крепкие слова Бро только текстом, 18+, по согласию, никогда о человеке, теле, еде |
| притворяется человеком | на прямой вопрос — честно; раскрытие в знакомстве (блок 6 §6) |

## 2. Слои защиты (сверху вниз)
1. **На телефоне до модели:** `CrisisGuard` (словарь + триаж), красные флаги симптомов и тренировки → стоп-протокол.
2. **Маршрут по цене ошибки:** «Здоровье» и SOS — самая сильная модель, лифт только вверх.
3. **Флаги в контексте:** `ed_care`, беременность и кормление, медфлаги, бережный режим — с первой реплики.
4. **Проверки ответа:** `ResponseGuard` (запрещённые темы, диагнозы, дозы), `NumberGuard`, валидатор полноты.
5. **Evals:** T1–T15, A30 §6, A38 §10.4, «ленивый ответ» — 100 % на каждой смене.

## 3. Дополнения
- **Номера помощи — только 112 и 911, везде** (решение основателя 07.11, контент-ревью «Решение основателя: везде 112 и 911», PR #43 влит). Определения страны нет. Пункт аудита A58 №7 «линии по странам» закрыт этим решением и не возобновляется в блоках Наставника. Винс в SOS говорит: «Я ИИ, не человек. Живые люди ответят по 112 и 911». Риск, записанный Агентами 10 и 7 (нет некризисной разговорной линии для уровня 2 по A07 §4.3), остаётся в их реестре; пересмотреть может только основатель.
- **Карточка «К визиту»** — новый выход режима «Здоровье»: собирается на телефоне, экспорт в PDF, без интерпретации.
