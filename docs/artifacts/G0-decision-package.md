## Уточнения основателя после первой версии пакета
- Аудитория — русскоязычные люди по всему миру, а не жители РФ; приложение используется не обязательно в России. Поэтому блокер 1 снимается, если основатель пользуется приложением вне РФ (подтвердить страну).
- Первый пользователь — основатель; стратегия — переход к enterprise-решению (D-007).

## Блокеры и важные находки
1. **Claude API официально не поддерживается в России** (A05, L-02). Использовать его из РФ — нарушение условий Anthropic. Все функции Must работают на правилах без ИИ-модели; ассистент (срез S6) ждёт решения.
2. **Условия WHOOP API запрещают постоянные копии данных WHOOP** (A05, L-05) — это конфликтует с хранением истории на телефоне. Нужен письменный вопрос в поддержку WHOOP API; до ответа храним производные показатели (личная норма, режим дня) и кэш в рамках разрешённого.
3. **Репозиторий публичный** — стратегия и e-mail видны всем. Рекомендация: сделать приватным, политику конфиденциальности вынести на отдельную публичную страницу (ссылка нужна WHOOP).
4. Новые риски от техлида: доступ к Cloudflare из РФ (проверить с телефона в срезе 1, запасной вариант — Yandex Cloud Functions); верификация разработчиков Google для установки APK вне Play; потеря ключа подписи.
