# Бриф аниматору: Lottie — топ-20 упражнений и 5 героических моментов Титана

Версия 0.1 · 2026-11-07 · авторы: Агент 4 (дизайн) с Агентами 15 (бренд), 12 (тренер), 13 (Android) · основание: решение основателя D-034 (заказать Lottie сразу), A40 §6, A37 §3 («линия света»), бриф иллюстратору `docs/design/concept-v3/illustrator-brief.md`, знак v2 (`brand/mark-v2/`).

## Зачем

В плеере тренировки (A40 §7) Титан показывает упражнение внутри кольца: человек видит движение краем глаза и не читает текст. Основатель решил не ждать и заказать профессиональную анимацию для 20 самых частых упражнений и для 5 «героических» моментов. Ради этих моментов человек и возвращается в Титан.

**Как это стыкуется с A40 §6.2.** Остальные 54 упражнения пока анимирует скелет Титана в Compose (`TitanPose`). Поэтому пропорции фигуры в Lottie должны совпадать с ригом (длины сегментов — ниже). Тогда соседние упражнения в одной тренировке выглядят как один герой.

## Стиль

- **Тот же Титан, что в знаке v2:** профиль головы, причёска и характер линии — как у R1 (`brand/mark-v2/master/hot-master-transparent.svg`).
  - Драпировку через плечо для упражнений убираем: она мешает читать движение. На бёдрах остаётся короткая повязка, как у R1 ниже пояса.
  - Окончательное «тот же герой» — за Агентом 15 на пилоте.
- **«Линия света» (A37 §3):**
  - фигура — это контур из светящейся линии поверх тёмной «стеклянной» выбивки;
  - линия градиентная: сверху белая, книзу в цвет режима;
  - внутренних линий минимум: ключица, линия пресса и колено намечены одним штрихом.
- **Толщина линии** постоянна в пикселях при любом масштабе: 14 px на холсте 1024 (≈ 1,4 %).
- **Пропорции = риг `TitanPose`** (A40 §6.2, в единицах роста 100):
  - торс 26, шея 3,6, голова 5,4;
  - плечо 14, предплечье 13;
  - бедро 21, голень 21, стопа 6.
  - Источник — `brand/mark-v2/source/geom.json` и `docs/design/training/src/pose.js`.
- **Реквизит** (гиря, перекладина, резинка, стена, коврик) — той же линией, но на 40 % тоньше и с прозрачностью 60 %. Он не светится, светится только Титан.
- **Движение:** вес и инерция настоящего тела, без мультяшных растяжений и «отскоков».
  - Пружинные дотяжки не больше 2–3 кадров.
  - В удержаниях (растяжки, дыхание) — едва заметное дыхание грудной клеткой 4–6 с. Фигура живая, но не дёргается.
- **Этика (A37 §3, Агент 10):** Титан — скульптура, а не эталон тела. Мышцы не утрировать. Нет пота, напряжённого лица и боли. В героических моментах — достоинство, без кулака в воздух и рёва.
- **Техника важнее красоты (Агент 12):**
  - нейтральная спина в приседе и махах;
  - колени по линии носков;
  - в подтягиваниях лопатки сведены, без раскачки;
  - в растяжках — без «провала» поясницы.
  - Ошибки из `mistakes_ru` не должны появляться ни в одном кадре.

## Технические требования (Агент 13)

| Параметр | Требование |
|---|---|
| Формат | Lottie JSON (Bodymovin из After Effects или экспорт LottieFiles); дополнительно `.lottie` по желанию. Исходники — только `.aep` (After Effects), обязательны |
| Холст | 1024 × 1024, фигура вписана в круг диаметром 820 px по центру (кольцо плеера рисует приложение). Линия пола — y = 900. Героические — тоже 1024 × 1024, с колоннами знака в тех же координатах, что у мастера (масштаб 0,5 от 2048) |
| Частота кадров | 30 fps для упражнений, 60 fps для героических моментов |
| Длительность | см. таблицы. Упражнения — **бесшовный цикл**: первый и последний кадр совпадают |
| Маркеры | у каждого упражнения маркеры с именами ключевых поз (`stand`, `bottom`, …) на кадре, где поза достигнута. Плеер проигрывает отрезки между маркерами и растягивает их под темп пользователя (`tempo` 3-0-1-0 → спуск 3 с) через `LottieClipSpec.Markers`. Удержания: маркеры `enter`, `hold_loop_start`, `hold_loop_end`, `exit`. Плюс маркер `poster` — статичный кадр для «уменьшить движение» |
| Сторона | анимируется **правая** рабочая сторона; левую приложение получает зеркалом по X. Асимметричных деталей (надписей, повязки на одной стороне) не делать |
| Слои и имена | `titan_line` (контур, Gradient Stroke), `titan_knockout` (выбивка, Fill), `titan_inner` (внутренние штрихи), `props_line`, `floor`. В героических: `columns_line`, `columns_knockout`, `ring`, `flash`. Имена — латиницей, без пробелов |
| Цвет режима | **только через dynamic properties** приложения: `LottieProperty.GRADIENT_COLOR` на `**/titan_line/**`, `COLOR` на `**/titan_knockout/**`, `**/props_line/**`, `**/ring/**`. Сдаваемый цвет — нейтральный (линия #FFFFFF → #9FEADC, выбивка #060E0D). Тема (тёмная / светлая) и режим (Разгон #FFB067, Ровно #7DE3D1, Бережно #A8A3FF) подставляются в коде |
| Свечение | **не делать эффектами AE** (Glow, Gaussian Blur, Drop Shadow поддерживаются Lottie на Android ограниченно [проверить на lottie-android 6.x]). Свечение рисует приложение под слоем Lottie. Допустимо: второй контур той же формы шире на 6 px с прозрачностью 25 % (`titan_line_halo`) |
| Запрещено | выражения (expressions), растровые изображения, текстовые слои, 3D-слои, Merge Paths, track mattes и маски сложнее одной (каждая — с согласования), эффекты AE, слои за пределами холста |
| Размер | упражнение ≤ 80 КБ JSON (≤ 25 КБ в gzip), героический ≤ 250 КБ. Не больше 40 shape-слоёв, ключи без лишних точек (сглаживание — easing, а не густые ключи) |
| Производительность | 60 кадров без пропусков на Pixel 6-классе в `lottie-compose`; проверка в приложении-образце от Агента 13 (APK пришлём) |
| Доступность (reduce motion) | при «удалить анимации» приложение показывает кадр `poster` — это главная ключевая поза, она должна читаться без движения. Героические моменты при этом — статичный финальный кадр |
| Звук | в Lottie звука нет. Тоны «Печати» и рекорда — отдельно, в приложении (A43 §1.3: музыка пользователя не прерывается) |
| Мелкий размер | упражнение должно читаться в круге 96 dp (карточка «дальше» на экране отдыха, A40 t4) — приложить PNG 96, 240 и 480 px |

## Что сдать

1. 20 файлов `ex-<id>.json` и 5 файлов `hero-<имя>.json`, имена — как в таблицах.
2. Исходники `.aep` одним проектом с общим ригом персонажа (Duik, RubberHose или свой — на выбор аниматора, но риг передаётся вместе с проектом).
3. Лист-контакт: все ключевые позы 20 упражнений в одну сетку (PNG 4K).
4. Видео-превью MP4 каждого файла на тёмном и светлом фоне в трёх цветах режима (подставить цвета вручную только для превью).
5. Таблица маркеров (CSV): файл, маркер, кадр.

Куда класть в репозитории (это делает Агент 13): `android/core/ui/src/main/res/raw/` или `assets/lottie/`. Исходники — в `brand/mark-v2/source/lottie/`, по аналогии с позами иллюстратора.

**Чек-лист приёмки каждого файла:**
- **Агент 12 (тренер):** техника по `technique_ru` в каждой ключевой позе; нет ошибок из `mistakes_ru`; темп отрезков между маркерами соответствует `tempo`.
- **Агент 3 (медицина):** нет положений, опасных при повторении (округлённая поясница под весом, колено внутрь, переразгиб в локте).
- **Агент 15 (бренд):** тот же Титан, что в знаке v2; линия одной толщины; читается в 96 dp; на листе-контакте «одна линия, один свет, один герой».
- **Агент 4 (дизайн):** холст, круг 820 px, пол y = 900; маркеры и имена слоёв по таблице; dynamic properties перекрашивают всё нужное в трёх режимах и двух темах; кадр `poster` читается.
- **Агент 13 (Android):** размер; нет запрещённых функций; 60 кадров в образце; зеркало по X без артефактов; цикл без «щелчка» на стыке.
- **Агент 10 (психология)** — для героических: достоинство без триумфа над кем-то, без стыда за тело.
- **Основатель:** финальное «да» по пилоту и по героическим моментам.
