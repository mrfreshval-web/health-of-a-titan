# Полировка по ревью сборки 119: что сделано

Источник: [README.md](README.md), решения — `triage.md` (PR #32). Ветка `claude/ux-polish-119`, один PR. Скриншоты «было / стало» — `brand/ux-polish-119/` в общей папке проекта (Robolectric, класс `UxPolishScreenshots`).

| # | Что сделано | Где |
|---|---|---|
| R1 | Общее правило чисел в `:core:ui`: `HotNumber` (табличные цифры, одна строка, без переноса), `HotTimeCell` (колонка времени 64 dp: начало моноширинным `HotType.time`, длительность мелко под ним), `HotNumbers.clock/span/duration`. В кольце Заряда при калибровке — одно число ночей, без дроби. Robolectric-тест `TodayPolishTest` проверяет на 360 dp, что самые длинные времена помещаются в одну строку | `HotNumbers.kt`, `DayItems.kt`, `TodayHero.kt` |
| R2 | Строки-статуса под шапкой больше нет. Отбой — последний узел «Линии дня» (один раз; время после полуночи теперь в конце дня, а не в начале) | `HotTopBar.kt`, `DayItems.kt` |
| R3 | Тап по делу открывает: тренировка → «Тренировка дня» (поток Б, оттуда плеер), завтрак/ужин → карточка «Тарелки дня» (поток В); остальные дела раскрываются на месте. Отметка — долгое нажатие или свайп вправо; 5 с висит «Отмечено: … · Отменить». Круглой кнопки-галочки больше нет | `DayItems.kt`, `HotApp.kt` |
| R5 | Вместо кольца «Норма готова 14/14» — полоска «Учусь тебя: N из 28 ночей» с отметкой 14 и пояснением по тапу. Числа сверены с движком: Заряд включается с 14 ночей (`RegimeEngine.MIN_BASELINE`, `MetricEngine.MIN_BASELINE_N`), полное окно — 28 (`RegimeEngine.FULL_NORM_DAYS`, `MetricEngine.BASELINE_DAYS`); тест сверяет `TodayTexts.NORM_NIGHTS` / `NORM_FULL_NIGHTS` с движком | `HotLearningBar`, `WhoopScreen.kt`, `TodayHero.kt` |
| R6 | Интента на календарь в коде нет. Гипотеза: система распознаёт дату/время в тексте экрана («суббота · 7 ноября», «отбой в 02:50») и предлагает действие. Окно приложения исключено из content capture; строка с «отбой в 02:50» убрана (R2). **Нужна проверка на устройстве** | `MainActivity.kt` |
| Y1 | У колец шапки пиктограммы: молния (нагрузка), шаги, месяц (до отбоя). Тап — три строки: что это, значение, одна строка смысла (strain 0–21, потолок режима) | `HotStatusRings.kt` |
| Y2 | Чипы — пиктограмма и число: сон (по тапу — состав ночи: глубокий, REM, лёгкий, без сна из данных WHOOP в памяти; нет фаз — «нет данных»), пульс («в покое, ночью, не сейчас»), потолок «≤ 12» со шкалой strain 0–21 | `TodayHero.kt`, `HeroTexts.kt`, `WhoopGlance.kt` |
| Y3 | Пилюля Заряда окрашена по зоне, под героем шкала «Заряд 32 · ниже твоей нормы» с отметкой «твоя норма — 50» и пояснением по тапу. Цвета — палитра режимов, не красный (красный только у SOS, A39 §7.1) | `TodayHero.kt` |
| Y4 | «Почему такой день ⌄» / «Свернуть ⌃», разворот на месте | `DayTextsUi.kt` |
| Y5 | Одна карточка в фокусе (дело сейчас или выбранный узел «Линии дня»), список «План» свёрнут, раскрывается тапом | `DayItems.kt`, `TodayScreen.kt` |
| Y7 | Кнопки «Журнал» нет; журнал открывается только долгим нажатием на знак WHOOP. Пользователю — «Синхронизировано в HH:MM»; на «Сегодня» — «WHOOP · синхронизировано в HH:MM», без счётчиков ночей | `WhoopScreen.kt`, `WhoopTexts.kt`, `TodayScreen.kt` |
| G1 | Пиктограмма еды — тарелка с вилкой и ножом; под выбранным узлом «Линии дня» — его название | `DaySection.kt`, `DayItems.kt` |
| G2 | При первом входе на «Наставника»: «Винс — твой наставник. ИИ, не врач.» | `MentorScreen.kt` |

**Не делали:** Y6 (номера помощи — ревью Агентов 7 и 10), Y8 и G3 (следующий срез).

**Ревью текстов.** Новые пояснения описывают данные и метрику, советов и диагнозов нет. Формулировки про фазы сна, пульс покоя, Заряд и норму помечены ⚑ для Агента 3 (`HeroTexts`, `HotNorm.explain`), строка Винса — для Агентов 12 и 10.
