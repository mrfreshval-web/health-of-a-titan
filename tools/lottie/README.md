# tools/lottie — Lottie Титана

Генератор Lottie-файлов (Агент 17, D-037; бриф `docs/design/training/animator-brief.md`). Он строит
топ-20 упражнений и 5 героических моментов из ключевых поз `content/training/poses.yaml`, то есть из
тех же поз, что и Compose-риг (`TitanPose.kt`).

v2 анимирует не контурного человечка, а Титана знака: рисунок из
`brand/mark-v2/master/hot-master-transparent.svg` нарезан на части по суставам («марионетка»,
cut-out rig). Мускулатура, ткань и свечение линии — как на макетах.

v3 добавляет Титану два вида, кроме фронтального:

- **Строгий профиль** (`front=False`). Руки и ноги нарисованы в профиль, в манере знака:
  - дельта, бицепс и трицепс;
  - квадрицепс с надколенником спереди и бицепс бедра сзади;
  - прямая большеберцовая кость и икра.

  Грудь глубже, спина шире. В этом виде все упражнения на полу и у стены.
- **Три четверти** (`front="3q"`, `threeq.py`). Это собственный фронтальный рисунок знака,
  повёрнутый так, как художник поворачивает фронтальный этюд:
  - ближняя половина сужена слабо, дальняя сильно;
  - ближние плечо и бедро стоят за линией позвоночника, дальние — перед ней (`rig.side_offsets`).

  В этом виде гоблет-присед и подтягивание: видны обе руки и вся мускулатура знака.

В фронтальном виде и в 3/4 дальняя сторона — зеркало ближней внутри своего прекомпа: один
рисунок на обе стороны.

## Сборка

```sh
cd tools/lottie
pip install skia-pathops pyyaml           # pathops режет рисунок знака
python3 -m hotlottie.build                 # все файлы
python3 -m hotlottie.build ex-pullup       # один файл
python3 -m hotlottie.keyposes              # дописать/исправить ключевые позы в poses.yaml
python3 ../../content/training/scripts/check_training.py   # проверить позы
```

Результат пишется в `android/core/ui/src/main/assets/lottie/<id>.json`, а список файлов с маркерами —
в `manifest.json`. Файлы лежат в core:ui, потому что героические моменты играют и экраны вне
тренировки (печать дня на «Сегодня»).

## Модули

| Модуль | Что делает |
|---|---|
| `brand.py` | Достаёт из мастер-SVG знака линию Титана и knockout (через `brand/mark-v2/android/svgflat.py`) |
| `cutout.py` | Нарезка рисунка знака на части по костям: плечо, предплечье, кисть, бедро, голень, стопа, голова, грудь, таз. Каждая часть переводится в локальные координаты кости и подгоняется по длине. Суставы закрыты дисками одного радиуса, а кольцо сустава видно только с внешней стороны сгиба. Кривые упрощаются (допуск 0,05 единицы рига) |
| `threeq.py` | Вид 3/4: фронтальные грудь, таз с повязкой и голова знака, суженные к дальней стороне |
| `drawn.py` | Части для вида сбоку, которых в знаке нет: руки и ноги в профиль (v3), голова в профиль, грудь, таз, стопа, кулак, пояс, юбка и клапан повязки. Нарисованы в манере знака: ленты контура и сужающиеся внутренние линии, всё заливками |
| `titan.py` | Сборка марионетки: части рук и ног — общие прекомпы для ближней и дальней стороны (дальняя — 45 % непрозрачности). Линия света — градиентная заливка `titan_line`. Ткань — вторичное движение: юбка следует за бедром, клапан — затухающий маятник от ускорения таза |
| `rig.py` | Прямая кинематика 12 суставов, как в `TitanPose.kt`; IK на две кости |
| `motion.py` | Сценарий движения: переходы между позами, easing (anticipation/overshoot), опоры (IK), пружины, дыхание на удержаниях, маркеры |
| `figure.py`, `lottie.py` | Билдер слоёв и ассетов, подгонка ключей кривыми Эрмита, JSON-строители |
| `shapes.py` | Контуры v1 (остались для реквизита и героев) |
| `props.py` | Пол, стена, косяк, турник, гиря, палка, резинка, ремень |
| `exercises.py` | Сценарии 20 упражнений: вид, опоры, кисти (кулак или ладонь), согнутая нога |
| `heroes.py` | 5 героических моментов: колонны из `HotMarkGeometry.kt`, кольцо, вспышка, крупный план «первого навыка» |
| `keyposes.py`, `posetool.py` | Новые и исправленные ключевые позы |

## Контракт с приложением

Имена групп — по брифу: `titan_line` (градиент из 3 стопов), `titan_knockout`, `titan_inner`,
`props_line`, `floor`, а в героях — `columns_line`, `columns_flutes`, `columns_knockout`, `ring`,
`ring_next`. Плеер (`core/ui/.../TitanLottie.kt`) перекрашивает их под режим и тему через dynamic
properties; путь `**` проходит и в прекомпы. Свечение рисует приложение: размытая копия кадра под
резким (API 31+).

Маркеры: `poster` — статичный ключевой кадр для «Удалить анимацию». У удержаний есть `enter`,
`hold_loop_start`, `hold_loop_end` и `exit`: вход играется один раз, затем дыхание крутится в петле.
Повторы растягиваются на цикл темпа пользователя.

Ограничения: 60 fps, 1024×1024, ≤150 КБ на файл (сейчас ≤97 КБ), ≤40 слоёв (сейчас 17–24). Без
выражений. Trim paths используются только в героях. Всё это проверяет `TitanLottieTest`.

## Превью

```sh
npm install                          # lottie-web; playwright с Chromium
node render/render.js storyboard out.png ../../android/core/ui/src/main/assets/lottie/ex-pullup.json
node render/render.js frames dir/ <file.json> 20 320 [rovno|razgon|berezhno|light]
node render/render.js sheet _top20.png 5 <files…>
node render/svg2png.js in.svg out.png 1024   # растр SVG (отладка нарезки, python3 -m hotlottie.brand)
```

Готовые превью лежат в папке проекта: v1 — `brand/lottie/`, v2 — `brand/lottie-v2/`, v3 — `brand/lottie-v3/` (с `_compare.png`: v2 | v3). Там раскадровки
по 6 кадров, GIF, `_top20.png` и `_heroes.png`.
